Tester API Docs

Xác thực

Mọi endpoint (trừ /api/health) yêu cầu API key, gửi qua 1 trong 2 header:

X-API-Key: <key>
# hoặc
Authorization: Bearer <key>

Key được cấu hình bằng biến môi trường API_KEY trong Vercel Project Settings → Environment Variables (xem .env.example). Nếu chưa set, mọi request sẽ bị từ chối (fail-closed), kể cả không có key.

GET /api/health

Không cần API key. Trả danh sách engine đang có.

curl https://<your-domain>.vercel.app/api/health

Engine thuần JS/TS (đã test chạy thật)

POST /api/luaegis/obfuscate

AST obfuscate: rename, encrypt strings/members, numbers, control-flow, minify, vmWrap.

Bodysource (string, bắt buộc), preset (light/medium/heavy/maximum), seed, rename, encryptStrings, encryptMembers, numbers, controlFlow, minify, vmWrap (boolean, tất cả optional)
Response{ success, output, mode, seed, localsRenamed, ... }
curl -X POST https://<domain>/api/luaegis/obfuscate \
  -H "Content-Type: application/json" -H "X-API-Key: $KEY" \
  -d '{"source":"print(1)","preset":"heavy"}'

POST /api/luaegis/vm

Bytecode VM (stack/register), nhiều lớp + DTC anti-dump probe. Nặng hơn — có thể chạm giới hạn thời gian của Vercel, xem phần "Giới hạn thời gian" bên dưới.

Bodysource, vmType (none/stack/register), vmLevel (debug/normal/max), vmLayers, padBytes, hookIntegrity, randomDtc, rename, preserveGlobals, encodeStrings, scrambleControlFlow, oneLine, seed
Response{ success, output, usedDtcId, seed, ... }

POST /api/luaegis/validate

Kiểm tra cú pháp Lua/Luau trước khi obfuscate.

Bodysource

POST /api/clyde/obfuscate

Base codebase mà luaegis được phát triển lên từ đó. Hỗ trợ VM mode (stack/register).

Bodycode (string, bắt buộc), options.noRename, options.noPreserve, options.encodeStrings, options.scramble, options.oneLine, options.vmType (none/stack/register), options.vmLevel (debug/normal/max)
Response{ success, output }

POST /api/clyde/validate

Bodycode

POST /api/veil/obfuscate

Engine của veil (self-leak bởi null, free to use). Chỉ phần lõi obfuscator được dùng, không kèm app/DB gốc.

Bodysource, preset (light/medium/heavy/maximum), các cờ boolean giống luaegis
Response{ success, output, mode, seed }

POST /api/lumora/obfuscate

Numerical VM 3 lớp XOR, port 100% sang JS thuần — không phụ thuộc Lua runtime nào, luôn chạy ổn định.

Bodysource
Response{ success, output, seed:{k1,k2,k3} }

POST /api/wearedev/obfuscate

Proxy thẳng sang API công khai của wearedevs.net — không phải engine riêng. Lưu ý: dùng API bên thứ 3 ở quy mô lớn (nhiều bot/nhiều request) nên kiểm tra điều khoản sử dụng của wearedevs.net trước.

Bodyscript

Engine Lua chạy qua wasmoon — thử nghiệm, chưa test thật

3 engine dưới đây là code Lua gốc được nhúng chạy trong 1 VM Lua 5.4 biên dịch sang WASM (thư viện wasmoon), không cần cài Lua lên server. Vì sandbox lúc viết code này không có mạng và không có Lua, các route này chưa được chạy thử thành công — hãy test kỹ bằng 1 đoạn code nhỏ ngay sau khi deploy trước khi dùng thật cho bot.

POST /api/25ms-obf/obfuscate [old]

Fork của Prometheus (không phải bản gốc của levno-710).

Bodysource, preset (ol/Normal/Vmify/Minify/me/Weak/doubled/Medium/Strong, mặc định Minify)

POST /api/hercules/obfuscate thử nghiệm

Bodysource, preset (light/balanced/heavy/maximum, mặc định balanced)

Preset maximum bật virtual_machine/bytecode_encoding — có thể dùng string.dump, nên rủi ro giống moonsecv2 bên dưới nếu test thấy lỗi, thử preset nhẹ hơn trước.

POST /api/moonsecv2/obfuscate thử nghiệm — rủi ro cao

Bodysource

Cảnh báo: engine này dùng string.dump() để lấy bytecode rồi tự parse — bytecode Lua gắn chặt với đúng version sinh ra nó. wasmoon chạy Lua 5.4, trong khi parser.lua nhiều khả năng được viết cho bytecode Lua 5.1. Nếu route này lỗi hoặc ra output hỏng, hướng xử lý đúng là host engine này trên 1 server Lua 5.1 thật (VPS/Render) rồi proxy sang, giống cách /api/wearedev đang làm — không phải sửa wasmoon.

Giới hạn thời gian chạy (Vercel)

Vercel Hobby (free): mỗi function tối đa 10 giây, không thể tăng. Vercel Pro: mặc định cao hơn, có thể cấu hình maxDuration trong vercel.json (đã set 60s cho các route nặng: luaegis/vm, 25ms-obf, hercules, moonsecv2, wearedev). Nếu bạn đang ở plan Hobby và VM nhiều lớp (vmLayers cao) bị timeout 504, giảm vmLayers/dùng preset nhẹ hơn, hoặc nâng lên Pro.

Proxy sang dịch vụ bên thứ 3

POST /api/voltfuscator/obfuscate proxy ngoài

Proxy sang voltils.cc. Cần API key Voltfuscator riêng của bạn (khác key của gateway này) — truyền qua voltKey hoặc set env VOLTFUSCATOR_API_KEY. Quota theo plan Voltfuscator (3-120 build/12h tuỳ plan), không liên quan quota của site này.

Bodycode, preset (normal/ultra), runtime (luau/lua51/roblox/studio/executor), voltKey

POST /api/xayz/obfuscate proxy ngoài

Proxy sang luaob.vercel.app. Không cần key, ~100 req/IP/giờ theo phía họ.

Bodycode, targetMode (roblox/standard)

POST /api/luna-moon/obfuscate headless browser, cực kỳ thử nghiệm

Site thật đã chuyển sang backend Convex, không còn logic client để trích xuất. Route này mở Chromium headless thật điều khiển bản mirror tự host tại /luna-moon-mirror/. Chưa test thật — xem README.md để tự chỉnh selector qua env var nếu lỗi. Cần Vercel Pro (cold-start Chromium > 10s của Hobby).

Bodysource
